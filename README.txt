UNIQUE PORTFOLIO WEBSITE — QUICK START

1. Download and extract unique_portfolio_website.zip.
2. Open the extracted folder.
3. Double-click index.html to open the website in Chrome.

No installation is required. This is a front-end portfolio website made with HTML, CSS and JavaScript.

PERSONALIZE IT:
- Open index.html in VS Code.
- Replace "Anupriya S" with your preferred display name.
- Update the About, project and skill descriptions to match your real work.
- Replace your.email@example.com with your actual email address.
- Change the sample project details and skill bar widths if needed.

PROFILE PHOTO:
The profile portrait is loaded from an online image URL, so an internet connection is needed to display it. To use your own photo, replace the image URL in the avatar img element in index.html.

NOTE:
The portfolio includes example projects and illustrative skill bars. Edit them to accurately reflect your own experience.
